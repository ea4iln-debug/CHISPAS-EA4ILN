Instalar Chispas

Entrenador y compañero de CW de EA4ILN para la Heltec WiFi LoRa 32 V3. Se instala por USB desde el navegador, sin instalar nada más.

Este navegador no puede usar el puerto USB. Abre esta página con Chrome o Edge en un ordenador (no sirven Firefox, Safari ni el móvil).
La página tiene que abrirse por https (o desde localhost) para poder usar el puerto USB.

Versión: cargando…

Antes de empezar

  • Chrome o Edge en Windows, macOS o Linux.
  • Un cable USB-C con datos (algunos solo cargan).
  • En Windows, el driver del CP210x de Silicon Labs (el conversor USB de la V3). Sin él, la placa no aparece en la lista.
  • Cierra cualquier otro programa que tenga el puerto abierto (monitor serie de PlatformIO, Arduino…).

Pasos

  1. Conecta la placa por USB y pulsa Instalar en la placa.
  2. Elige el puerto (CP2102 o USB to UART) y pulsa Conectar.
  3. Pulsa Install Chispas EA4ILN. Te preguntará si quieres borrar la placa:
    • Sin marcar (lo normal): se conserva lo guardado en la placa (indicativo, locator, memorias, estadísticas, red WiFi y lista de parques POTA).
    • Marcado: borra toda la memoria. Úsalo si la placa traía otro programa (Meshtastic, por ejemplo) o si Chispas se comporta raro tras instalar.
  4. Espera a que termine (un minuto, más o menos). La placa se reinicia sola.

Si no conecta, mantén pulsado el botón PRG, pulsa y suelta RST, suelta PRG y vuelve a intentarlo. Tras instalar, la opción Logs & Console del mismo diálogo muestra el monitor serie.

Siguientes versiones

Una vez instalado, Chispas se actualiza solo por WiFi: CONF > CONFIG > ACTUALIZAR FW. Esta página sirve para la primera instalación o para recuperar una placa.

Esta página instala siempre la última versión final publicada en GitHub (las beta, solo por OTA).
